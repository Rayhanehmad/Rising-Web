# Rising Solution — Engineering Consultancy Website

Production-ready Next.js 14 App Router website designed for GitHub + Netlify deployment.

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production test

```bash
npm run build
npm start
```

## GitHub

```bash
git add .
git commit -m "Build Rising Solution engineering consultancy website"
git push -u origin main
```

## Netlify

Connect the GitHub repository and use:

- Build command: `npm run build`
- Node: 20
- Do not add a generic SPA fallback.

## Important content note

Only verified company information should be published. Replace any TODO/placeholder contact or credential information before production.

The project intentionally does not invent client logos, testimonials, awards, certifications, project counts, or project outcomes.
